# 水下考古潜水记录

直接打开 `index.html` 使用。点击平面图添加标记，支持筛选、编辑、删除、时间线和导出JSON。

## 借展排期

- `index.html` — 遗物标记页：在原有点位功能上，为遗物登记馆藏号、保存等级与交接签字。
- `loan.html` — 借展排期页：选择借展单位、巡展站与展柜排入借展；同一展柜日期相撞不予排期；保存不稳或签字缺失的遗物自动留在待处理；启运时原交接记录冻结留档，之后只能调整归还日或展柜（追加修订记录）；押运人视图可按姓名查看当前生效安排；展柜档期按巡展站一览。
- `rules.html` — 借展规则页：内容由 `js/rules.js` 渲染。

## 文件分工（各放一处）

- `js/rules.js` — 借展规则唯一出处：保存等级、借展单位、巡展站/展柜、运输条件、撞期与启运后调整规则。
- `js/store.js` — 排期档案唯一存放处：点位与借展记录都保存在 localStorage（`zfl30Marks` / `zfl30Loans`）。
- `js/nav.js` — 页面连接唯一出处：三个页面共用的导航链接。
- `css/app.css` — 共用样式。
