# 水下考古潜水记录 / 沉船出水物巡展借展排期

直接打开 `index.html` 使用（各页面请在同一浏览器下使用，数据存于 localStorage）。

## 页面与文件

- `index.html` — 点位地图：点击平面图添加标记、类型筛选、潜次时间线、导出 JSON（原功能不变，只看点位）。
- `loans.html` — 借展排期工作台：遗物挂馆藏号/保存等级/签字，维护借展单位与运输条件、巡展站与展柜，提交借展排期、登记启运、启运后调整。
- `archive.html` — 排期档案唯一存放处：交接记录与调整留档只读可查；押运人按姓名查看“以此为准”的最新安排。
- `rules.html` — 借展规则唯一发布处。
- `nav.js` — 页面连接统一维护处（增删页面只改这里）。
- `store.js` — 排期数据与规则校验（可排判定、展柜档期相撞、调整差异）。

点位数据键为 `zfl30Marks`，借展数据键为 `zfl30LoansV1`。

## 主要规则

1. 遗物须有馆藏号、保存等级、负责人签字；保存不稳定或缺签字者留在“待处理”，不能排期。
2. 同一巡展站同一展柜日期相撞，整单不排。
3. 运输条件书面登记并勾选确认，不再电话口头确认。
4. 启运登记押运人并留存当时安排快照；启运后仅能调展柜和归还日，原交接记录保留不删改，押运人在档案页可见新安排。
